# Блог caloriept.ru — правила

Сайт — лендинг бота-счётчика калорий CaloriePT AI (@Calorie_counter_rf_bot) студии AIStudioDimkoFF.
Цель блога — SEO-трафик из Яндекса на статьи о питании и калориях и переходы в бота.
Расписание: каждый день новая статья, публикуется сразу (владелец разрешил публиковать без согласования).

## Как выбрать тему
1. Взять первую тему со статусом «в очереди» из `база-статей.md`.
2. Проверить запрос в подсказках Яндекса (см. «Сбор запросов») и что на сайте нет статьи с тем же интентом.
   Если интент уже закрыт — выбрать следующую тему или предложить углубить старую статью.
3. Если в очереди меньше 5 тем — добавить новые по подсказкам Яндекса (по 5–10 запросов на тему).

## Сбор запросов (Вордстат может быть недоступен)
Во встроенном браузере открыть https://ya.ru/search/?text=<запрос> и выполнить на этой странице:
`await (await fetch('/suggest/suggest-ya.cgi?srv=serp_ru_desktop&uil=ru&v=4&part='+encodeURIComponent('<запрос>'))).text()`
Это подсказки Яндекса — реальные формулировки людей. Основной запрос — короткий и частый, дополнительные — 5–10 хвостов.
Капчу не решать: если Яндекс показывает капчу — использовать WebSearch и общие знания о запросах.

## Качество
- Объём 1400–1600 слов (верхняя граница нормы), простой язык, без ИИ-клише и воды.
- Структура: H1 с запросом; «## Коротко» 3–4 пункта; H2 в форме вопросов; таблицы и списки, где уместно;
  «## Частые вопросы» с 4–5 «### вопросами» (разметка FAQPage); «## Итог»; «## Источники».
- Медицина и питание — только проверенные факты: ВОЗ (who.int/ru), научные статьи (PubMed), Роспотребнадзор, NICE.
  Не уверен в цифре — не писать. Никаких обещаний «похудеете на N кг», никаких диагнозов и лечения.
  Беременным, подросткам, при болезнях — «к врачу». Внизу статьи генератор сам добавляет оговорку.
- Калорийность продуктов — с пометкой «по данным таблиц/упаковки, у разных производителей отличается».
- Функции бота описывать только реальные (см. «Что умеет бот»). Ссылки: 1–2 на бота https://t.me/Calorie_counter_rf_bot,
  2–3 на другие статьи блога (`/blog/<slug>/`), описательными анкорами.
- Мета: title до 60 символов, description до 160, slug латиницей через дефис.
- Фото и картинки сайта не менять, в статьи картинки не добавлять.

## Что умеет бот (сверено с кодом calorie-bot, 2026-10-09)
Расчёт нормы по Миффлину — Сан Жеору (×1,375, цель ±300 ккал); КБЖУ по фото (дневной лимит фото), штрихкод, чек из ресторана;
дневник и статистика за день/неделю, мини-приложение; холодильник по фото → список продуктов → рецепты под норму;
меню на день и план на неделю; нутрициолог Анна в трёх режимах (Мягкая, Строгая, С юмором) и вечерний итог дня;
цикл: 4 фазы, в лютеиновую +200 ккал, советы по фазам; вода: цель вес × 30 мл, кнопки +150/+250/+500, напоминания;
оценка рациона 0–100 по 6 составляющим; анализ привычек за 30 дней; режим праздника; удаление данных в профиле. Вход без подписки.

## Публикация
1. Сохранить статью в `content/blog/<slug>.md`.
2. `py -3 tools/build_blog.py` (собирает blog/, sitemap.xml) — должно написать «Собрано статей: N».
3. Добавить ссылку на новую статью в 1–2 старые статьи по теме (в content/blog/*.md) и пересобрать.
4. Карточки статей на главной (`index.html`, блок `id="articles"`) — показываются 4 последние/главные; при желании заменить одну.
5. `git add content blog sitemap.xml index.html` → коммит → `git push origin main` (GitHub Pages, сайт обновится за 1–2 минуты).
6. Проверить `curl https://caloriept.ru/blog/<slug>/` → 200.
7. Яндекс Вебмастер → https://webmaster.yandex.ru/site/https:caloriept.ru:443/indexing/reindex/ → отправить адрес статьи
   (если во встроенном браузере нет входа в Яндекс — пропустить и написать владельцу).
8. Отметить тему в `база-статей.md` как «опубликована» с датой и адресом.
